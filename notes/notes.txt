Matheutic currently focuses on equation worksheets. If it evolves, likely directions include:

- More exercise types (missing number, number bonds, multi-step chains)
- Difficulty progression / leveling presets
- Simple session mode (timed practice, daily set)
- Optional “brain-fitness” suite branding (e.g., **Mathwell**) if the scope expands

## Contributing

Issues and PRs are welcome.

If you contribute generator logic, please keep these principles:
- predictable constraints
- printable layouts
- easy-to-read presets
- no “gotcha” problems (unless explicitly requested)
